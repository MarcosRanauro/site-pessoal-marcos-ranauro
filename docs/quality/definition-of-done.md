# Definition of Done — Site Pessoal Marcos Ranauro

## Objetivo

Definir quando uma entrega pode ser considerada pronta neste projeto.

---

## Uma entrega só está pronta quando:

- [ ] Resolve exatamente o que foi pedido.
- [ ] Não adiciona funcionalidades fora do escopo.
- [ ] O layout está responsivo.
- [ ] O visual segue a identidade aprovada.
- [ ] O código está organizado.
- [ ] Não há CSS inline desnecessário.
- [ ] Não há `console.log` esquecido.
- [ ] Não há erro no console do navegador.
- [ ] O projeto roda localmente.
- [ ] O build funciona.
- [ ] O `CONTEXT.md` foi atualizado, se a alteração for relevante.
- [ ] O `DECISOES.md` foi atualizado, se houve decisão importante.

---
