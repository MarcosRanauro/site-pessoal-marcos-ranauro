# Escopo — Site Pessoal Marcos Ranauro

## Objetivo

Definir o que entra e o que não entra na primeira versão do site pessoal de Marcos Ranauro.

---

## Escopo da V1

A V1 será um site one-page profissional, responsivo e publicado na Vercel.

---

## Seções obrigatórias

A primeira versão deve conter:

- Header
- Hero
- Sobre
- Stack
- Projetos
- Serviços/Soluções
- Processo
- Diferenciais
- Contato
- Footer

---

## Funcionalidades obrigatórias

- Navegação entre seções
- Layout responsivo
- Botões de contato
- Links para GitHub e LinkedIn
- Seção de projetos
- Seção de tecnologias
- SEO básico
- Favicon
- Metadados principais
- Deploy na Vercel

---

## Funcionalidades desejáveis

Podem entrar se não atrasarem a V1:

- animações suaves;
- microinterações em cards;
- alternância PT-BR / EN;
- imagem Open Graph;
- página 404 personalizada;
- currículo para download.

---

## Fora do escopo da V1

Não implementar agora:

- login;
- cadastro;
- dashboard;
- banco de dados;
- Supabase;
- painel administrativo;
- pagamentos;
- blog com CMS;
- área privada;
- API complexa;
- sistema de comentários;
- formulário com persistência em banco;
- integração com IA.

---

## Critérios de aceite

A V1 só será considerada pronta se:

- [ ] O site rodar localmente sem erro.
- [ ] O site estiver responsivo.
- [ ] O visual seguir a identidade aprovada.
- [ ] O hero comunicar claramente quem é Marcos Ranauro.
- [ ] As seções principais estiverem presentes.
- [ ] Os links principais funcionarem.
- [ ] O contato estiver visível.
- [ ] O SEO básico estiver configurado.
- [ ] O projeto fizer build sem erro.
- [ ] O deploy na Vercel funcionar.
- [ ] `CONTEXT.md` estiver atualizado.
- [ ] `DECISOES.md` estiver atualizado com decisões relevantes.

---

## Regra principal

A V1 deve ser simples, elegante e bem executada.

Não adicionar funcionalidades extras antes de concluir a base visual, responsiva e publicável.
